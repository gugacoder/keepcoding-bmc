## Products: Keep Solo and KeepBiz

Keep Solo: lighter app for solopreneurs—self-serve dashboard, agents observe their solo workflows, build wrapper tools, learn, take over routine stuff. No team, just one person scaling.

KeepBiz: suite for PMEs com Retaguarda—same idea but scaled: agents handle back-office ops, dashboard for self-mapping, handover to product mode.

Both share the core loop:
1. Deliver wrapper apps
2. Agents learn from use
3. Handover dashboard
4. Exit agency service

---

### Keep Solo - Three Rooms

Both apps have three main parts:
1. Monitor (Input/Status): Dashboard showing funnel health—leads in, conversions out, content performance
2. Create (Content Engine): Where the user schedules posts, generates ideas, drafts content. Calendar view, drag-drop, AI prompts
3. Agents (Helpers): Companion zone. List of helpers, chat-like interface, autonomous hints and suggestions

The glue: a tiny home bar at bottom—three icons: Eye (Monitor), Pen (Create), Robot (Agents).

---

Keep Solo is NOT just for writers—it's for any solopreneur: mechanic, baker, tutor, freelance designer, personal trainer, etc. The three rooms adapt to whatever the user does.

The agents are powered by the Workflow factory, so they learn from whatever the user does. A mechanic drops "oil change log" → agent auto-fills forms, schedules reminders.

---

### KeepBiz - Scaled Version

Not just "bigger Keep Solo." It's a three-zone fortress:

Zone 1: Social Monitor – "The Mirror"
- Agents crawl web/social (mentions, reviews, trends), aggregate into reputation score + alerts
- Passive intel dashboard

Zone 2: Content Forge – "The Megaphone"  
- Process templates, not just content
- Calendar shows agent progress on tasks
- Swarm of agents split work: research, draft, schedule

Zone 3: Agent Core – "The Engine Room"
- Multi-agent management with roles: "Invoice Hunter", "Lead Nurturer", "Schedule Keeper"
- Department-aware, with permissions
- Status monitoring: Idle, Working, Waiting on data

Fourth part (the glue): Orchestrator Bar—shows "Team Status": green if all agents are humming, yellow if bottleneck.

---

### KeepBiz Key Principles

- Apps are the main door, not direct agent chats
- Data stays inside the app's sandbox
- Top brass (CEO, ops lead) can chat agents if needed, but everyone else uses the delivered app
- Default to app-first: When creating agent, auto-prompt "Want this as a standalone bot? Or wrap it in an app?"
- RBAC lite: Use presets, no deep menus. Drag-drop like Slack channels
- Human-in-loop for high-stakes (money, contracts)
- Audit log: every action logs—who triggered, what data touched

---

### Workflow Mapping - Leisure Experience

How mapping happens (leisure version):

1. **Voice-first kickoff**: Owner taps "New Workflow" → mic icon. Just talk: "Hey, every Monday I log client calls into Sheets, then email follow-ups." No typing.

2. **Watch & learn mode**: Agent says: "Show me once." Owner does the task on their real tools—agent screen-records silently. "Got it—want me to try next time?"

3. **Doodle & tweak**: Agent auto-sketches a visual flow (bubbles + arrows). Owner drags bubbles, adds conditions. Like mind-mapping with a buddy.

4. **Test drive**: Agent runs a shadow version: "I'm doing it now—watch." Owner sees output. If wrong, say "Nope, add CC to boss." Agent fixes, remembers.

5. **Autopilot handover**: Owner hits "Activate"—agent goes live. "Monday log done, follow-ups out. Anything?"

Zero friction. No learning curve—use your voice and hands like normal.
