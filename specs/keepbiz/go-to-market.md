# KeepBiz -- Go-to-Market e Modelo de Negócio

---

## Estratégia: de Agência a Produto

O KeepBiz nasce como serviço hands-on e evolui para produto self-service. O objetivo é usar os pilotos para construir e validar o dashboard -- e depois sair do modo serviço.

| Fase | O que fazemos | Receita | Relação com cliente |
|---|---|---|---|
| **Piloto (agora)** | Hands-on: mapeamos workflows, construímos apps-wrapper, treinamos agentes | Assinatura piloto + taxa de setup | Onboarding pessoal + check-ins semanais |
| **Transição** | Entregamos dashboard self-service; cliente mapeia seus próprios fluxos | Assinatura de plataforma | Dashboard self-service + suporte via chat |
| **Escala** | Clientes do mundo todo se servem; mantemos a plataforma | SaaS global | Comunidade/fórum + atualizações automáticas |

> **Meta:** A receita dos pilotos financia o dashboard. Quando o dashboard está pronto, saímos do modo serviço. O cliente mapeia sozinho; nós mantemos a plataforma.

## O dashboard self-service (o produto real)

O verdadeiro produto da Keep Coding não é o serviço de mapeamento -- é o **dashboard onde o cliente mapeia seus próprios fluxos**. Tudo que fazemos na fase piloto é construir e validar esse dashboard.

Quando o dashboard está pronto:
1. Cliente acessa a plataforma
2. Descreve suas tarefas (interface de mapeamento)
3. Sistema auto-gera apps-wrapper via Workflow factory
4. Agentes começam a observar
5. Nós não precisamos estar envolvidos

> "We build a dashboard for us, then deliver it to the world."
> "We start hands-on to build trust, then we fade out."
> "Dashboard takes over, we don't babysit."
